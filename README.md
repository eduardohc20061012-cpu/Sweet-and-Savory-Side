### ¿De que va nuestro sitio?
###### Es una plataforma web desarrollado con javascript y PostgreSQL que permitira a los usuarios buscar, categorizar y aprender sobre el area culinario de forma digital. 



### Instalacion de nuestro proyecto 
 **Si es un colabolador, realize una descarga de como instalar los archivos de nuestro repositorio.**
###### 1. Copie el link de "SSH"
###### 2. Cree una carpeta donde ira referenciado el repositorio
###### 3. Realice un "control-remote" para vincular su ordenador al repositorio en linea
###### 4. Entre al cmd en direccion a la carpeta creada y posteriormente ingrese git clone  y comienze a trabajar en el proyecto

### ¿Por que se creo este sitio web?
###### El sitio web tiene el proposito de contribuir en el aprendizaje culinario, para usuarios interesando en aprender o quienes desean probar algo nuevo en su dia a dia. Esta viene integrada con un Inteligencia Artificial enfocada en el area culinaria que orientada a los usuarios en el manejo de ingredientes, recomendaciones y sugerencias para el desarrollo de un platillo.
